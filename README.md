## Use the explorer

1. **Choose a collection:** Papers or Open source.
2. **Narrow the question:** select tags within a row (OR), then combine rows (AND). Example: `world_model` AND `intersection`.
3. **Read:** search titles, sort by year, expand abstracts and pack notes.

## GitHub Pages

The workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) builds `site/` and deploys to GitHub Pages with base path `/wm-vla-vln-vlm-survey/`.

To enable Pages on this repository (maintainers):

1. Wait for the **Deploy site to GitHub Pages** workflow to succeed on `main`.
2. Open **Settings → Pages**.
3. Set **Source** to **GitHub Actions**.
4. Optionally set the repo homepage (About) to `https://topsun-bot.github.io/wm-vla-vln-vlm-survey/`.

This agent cannot change those GitHub settings.

## Method

1. **Inputs:** world-model table + VLA / VLN / VLM table + agent-controls-robot landmarks. Entries were checked against the arXiv API and/or abs pages.
2. **Dedup:** primary key is arXiv ID without `vN`; otherwise a normalized title.
3. **Tags:** `world_model`, `VLA` / `VLN` / `VLM` / `intersection`, `agent-robot` / `llm-agent`. Multi-source rows keep the union.
